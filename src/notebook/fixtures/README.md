# Import test fixtures

These are synthetic parser scenarios, not a person’s reading history. Public book metadata is retained to exercise catalog matching. Review and private-note text is generated test prose. Goodreads status, ratings, shelves, ownership, and dates are rebuilt from deterministic test cases; StoryGraph statuses and selected date/rating cases are defined by the assertions. The samples cover CSV quoting, HTML reviews, status changes, dates, ratings, and deduplication.
